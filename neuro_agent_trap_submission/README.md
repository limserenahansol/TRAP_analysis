# Neuro-Agent TRAP submission package (updated 20-mouse cohort)

Submission package for **Yiqi Jiang / Neuro-Agent** benchmark: TRAP whole-brain density analysis (MATLAB Step 13 analogue in Python).

## What changed vs the earlier upload

| Before (old upload) | Now (this package) |
|---------------------|---------------------|
| ~8 mice, cohort 1 only | **20 mice** (cohort 1 + cohort 2) |
| Partial manifest | Full manifest from `TRAP_sample_manifest_no.csv` |
| Old density export | Combined workbook `Hansol Lim 561 cell counts + density.xlsx` |
| `calculated_mm3` tree | Same — `cells/sample volume in mm^3` |

**Excluded mouse:** `HaLi_020326_11` (`include=0` in manifest).

## Package contents

```
neuro_agent_trap_submission/
  task.md              # Research question & task spec
  rubric_items.md      # Grading / reasoning checklist
  solver.py            # Python Step-13-style analysis
  build_package.py     # Re-export data/ + reference outputs from TRAP_analysis_sync
  requirements.txt
  README.md
  LINKS.md
  data/                # Processed inputs (generated by build_package.py)
  outputs/
    reference_matlab_step13/   # Copied MATLAB figures/CSVs

```

## Quick start

```bash
cd TRAP_analysis_sync/neuro_agent_trap_submission
pip install -r requirements.txt
python build_package.py
python solver.py
```

Requires the combined workbook at:

`../Hansol Lim 561 cell counts + density.xlsx`

and MATLAB reference outputs under:

`../TRAP_OUTPUT_calculated_mm3/13_universal_cluster_PCA_density/forebrain_no_bs/z_within_phase/`
